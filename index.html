实习项目

《极品飞车：集结》沙海惊鸿赛道

腾讯天美 Timi Studio · 2025.07 — 2025.10 · 暑期实习独立完成

点击查看大图
项目概述

在腾讯天美实习期间，独立完成沙海惊鸿赛道的关卡设计，负责赛道白盒搭建、视觉元素布置与玩法验证。关卡白盒阶段获得 8万+ 玩家点赞，为该项目首条 C 级封闭场景赛道。

负责内容
  • 赛道整体规划与难度曲线设计
  • 封闭场景空间节奏控制
  • 视觉引导系统与美术协作
  • 玩法体验调优与玩家反馈迭代
设计思路

以沙漠为主题，通过视觉引导与节奏控制，在高速竞速中营造紧张追逐感。封闭场景设计保证了 C 级难度的可控体验，同时兼顾不同水平玩家的通关感受。

个人 Demo

《文物修复师——传说博物馆》

独立开发 · UE5 · 2025

点击查看大图
项目概述

以博物馆为背景的叙事解谜游戏。玩家扮演一名博物馆管理员，在夜间巡查中揭开传说博物馆的秘密——"规衡"被破坏，时空长河面临危机。含完整的关卡设计白盒文档与 UE5 实现。

核心玩法
  • 放大 / 缩小物体：瞄准物体边缘，滚轮切换尺寸（0.5× / 0.75× / 1× / 1.5× / 2×），修复污染点，达成"规衡"
  • 放大 / 缩小自身：Q 键放大（2×），E 键缩小（0.25×），变大秒杀敌人，变小穿越窄缝
关卡结构

分为 5 个阶段：进入博物馆 → 遭遇异常 → 进入规衡空间 → 学习能力 → 修复与 BOSS 战。"规衡"为核心理念，规衡空间由纯粹几何体构成，是象征尺度与平衡的标志物。

设计文档

完整输出前期思考、关卡目标、阶段流程、核心场景（博物馆 + 规衡空间）、放大缩小玩法系统等设计文档。

关卡分析

《塞尔达传说：旷野之息》初始台地拆解

个人分析 · 53页 · 建筑学视角 · 2025

点击查看大图
分析框架

以凯文·林奇城市意向理论与彭一刚《建筑空间组合论》为核心框架，融合德西自我决定理论（SDT）、艾宾浩斯记忆曲线与心流理论，对初始台地教学关卡进行系统性多学科拆解，输出 53 页专业分析文档。

设计目标
  • 完成玩法机制教学：基础操作 → 特色玩法 → 开放世界三阶段递进
  • 完成故事引入：海拉鲁背景 + 林克新剧情动力 + 世界观渗透
  • 将机制教学与游戏叙事深度融合，打破传统"先教学关卡—后开放世界"的割裂感
关卡结构

抽象为两层：① 复苏神殿 → 初始高塔 → 四大神庙 → 时之神殿的阶段关卡序列；② 节点间开放世界填充（推荐路径、环境、碎片关卡）。采用弱引导策略，用环境地形、空间布局与氛围引导玩家自然探索推荐路径，规避"空气墙"对开放世界体验的破坏。

理论应用
  • 凯文·林奇城市意向五要素：路径（推荐路径）、边界（高原绝壁）、区域（东南西北四区）、节点（初始高塔、神庙入口）、地标（时之神殿尖顶）
  • 德西自我决定理论 SDT：自主性（高自主权）、胜任感（教学五阶段渐进）、归属感（与老人、塞尔达的对话）
  • 心流理论：目标清晰 / 无干扰 / 即时反馈 / 持续挑战，维持"心流通道"
  • 彭一刚《建筑空间组合论》：对比与变化、重复与再现、衔接与过渡、渗透与层次、引导与暗示、序列与节奏
核心结论

初始台地是"教学即体验"的典范：任天堂用弱引导将整个海拉鲁大陆的精华浓缩于一片高原，通过"形式追随功能"的空间组织，让玩家在探索中自学成才，在叙事徐徐展开的同时获得探索海拉鲁的能力与勇气——这是建筑空间叙事思维在游戏关卡设计中的完美印证。
